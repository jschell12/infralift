# 0003. Adopted resources get generated code, not guessed code

**Status:** accepted, 2026-11-08

## Decision

When adopting resources built by hand in a cloud console, infralift writes only `import {}` blocks, a provider and a backend. The resource code is generated by Terraform from what is actually running (`plan -generate-config-out`) in the customer's CI, then held to the zero-change gate ([0002](0002-zero-change-import-gate.md)).

## Why

The codegen that writes resource blocks from an assessment's inventory guesses attributes from metadata, and some guesses are wrong: DigitalOcean droplet sizes are read from a field the connector does not set, so every droplet becomes the smallest size. Taking over a resource with guessed code would resize or replace it. Generated code describes the real resource.

## Cost

The generated code is verbose and sometimes needs hand edits before the plan passes. The check commits it to the PR branch with the workflow's own token, which starts no new workflow run, so the check records its result on that commit itself.
